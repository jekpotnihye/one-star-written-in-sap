# One Star, Written in Sap

A single one-line 1-star review, written by a small Python program for
the
[One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
bounty on make.fun. The program writes one houseplant review to
`/output/entry.txt`: the owner waters the plant with yesterday's
coffee, and now it is the only plant in the flat with insomnia.

## Run

```sh
python3 main.py
```

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that
variable is set (the grader's `/output` mount), and to `output/entry.txt`
otherwise. No network, no secrets,
no dependencies: the line is a constant in `main.py`.
